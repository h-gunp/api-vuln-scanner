# 프론트앤드 기능명세서

일단 핵심 기능만 추려봤습니다.

| 기능 ID | 기능명 | 설명 |
| --- | --- | --- |
| FE-DASH-001 | 검사 URL 입력 | 사용자가 검사할 대상 서비스의 URL을 입력한다. 1차 목표에서는 vuln-bank URL을 기본값으로 제공한다. |
| FE-DASH-002 | 스캔 실행 | 입력한 URL을 대상으로 API 보안 스캔을 시작한다. |
| FE-DASH-003 | 스캔 결과 요약 | 스캔 상태, 검사 대상 URL, 발견 API 수, Finding 수를 표시한다. |
| FE-DASH-004 | API 상세 조회 | 발견 API 수를 클릭하면 검사한 API 목록과 상세정보를 표시한다. |
| FE-DASH-005 | Finding 현황 조회 | 전체 Finding 수와 취약점 유형별 개수를 표시한다. |
| FE-DASH-006 | Finding 상세 조회 | Finding 현황을 클릭하면 취약점 유형별 원형 그래프와 발견된 Finding 목록을 표시한다. |
| FE-DASH-007 | 취약점 유형 필터링 | Finding 상세 화면에서 특정 취약점 유형을 선택하면 해당 유형의 Finding만 표시한다. |
| FE-DASH-008 | Finding 세부사항 조회 | 각 Finding의 자세히 보기 버튼을 클릭하면 대상 API, 판정 결과, 요청·응답 증거 및 취약점 설명을 표시한다. |
| FE-DASH-009 | 상세 화면 검색 | API 및 Finding 상세 화면에서 검색어를 입력하여 원하는 항목만 조회한다. |
| FE-DASH-010 | AI 리포트 조회 | 스캔 결과에 대한 AI 분석 요약과 개선 권고를 표시한다. |
| FE-DASH-011 | 보고서 미리보기 | AI 리포트 상세 화면에서 최종 보고서 내용을 미리 확인할 수 있도록 한다. |
| FE-DASH-012 | 보고서 다운로드 | AI 리포트 상세 화면에서 최종 보고서를 파일로 다운로드할 수 있도록 한다. |
| FE-DASH-013 | 유저 정보 입력 란 | 후순위 |
