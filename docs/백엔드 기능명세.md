# 기능명세

# 4.1 스캔 관리

| 기능 ID | 기능명 | 설명 | 입력 | 출력 | 관련 API |
| --- | --- | --- | --- | --- | --- |
| BE-SCAN-001 | 검사 URL 검증 | 프론트에서 입력한 검사 URL의 형식과 허용 범위를 검증한다. | target_url | 검증 결과 | POST /api/scans |
| BE-SCAN-002 | 스캔 생성 | 새로운 스캔을 생성하고 scan_id를 발급한다. | target_url | scan_id | POST /api/scans |
| BE-SCAN-003 | Target Profile 생성 | 입력 URL과 서버 설정을 이용해 Scanner용 target_profile.json을 생성한다. | scan_id, target_url | target_profile.json | 내부 처리 |
| BE-SCAN-004 | Scanner Job 생성 | Scanner Worker에 실행할 작업을 등록한다. | scan_id, target_profile_ref | task_id | 내부 처리 |
| BE-SCAN-005 | 스캔 상태 관리 | 전체 스캔의 상태와 현재 단계를 관리한다. | scan_id, status, stage | 스캔 상태 | 내부 처리 |
| BE-SCAN-006 | 스캔 상태 조회 | 프론트에 현재 스캔 상태를 반환한다. | scan_id | status, stage, progress | GET /api/scans/{scan_id} |
| BE-SCAN-007 | 스캔 완료 처리 | scan_result.json 저장 완료 후 스캔 상태를 완료 처리한다. | scan_id | completed | 내부 처리 |
| BE-SCAN-008 | 스캔 실패 처리 | 전체 스캔 실패 시 오류 내용을 저장한다. | scan_id, error | failed | 내부 처리 |

### 스캔 상태

```
QUEUED
RUNNING
COMPLETED
FAILED
```

### 세부 Stage

```
PROFILE_LOADING
AUTHENTICATING
DISCOVERING
NORMALIZING
OBJECT_DISCOVERY
RELATIONSHIP_ANALYSIS
PLANNING
POLICY_VALIDATION
EXECUTING
VERIFYING
```

# 4.3 API 탐색 결과 관리

| 기능 ID | 기능명 | 설명 | 입력 | 출력 | 관련 API |
| --- | --- | --- | --- | --- | --- |
| BE-API-001 | API Graph 수신 | Scanner의 normalized_api_graph.json을 수신한다. | normalized_api_graph.json | 검증 결과 | 내부 처리 |
| BE-API-002 | API Graph 저장 | 전체 정규화 결과를 Artifact로 저장한다. | normalized_api_graph.json | artifact_ref | 내부 처리 |
| BE-API-003 | Endpoint 저장 | operations를 Endpoint 단위로 DB에 저장한다. | operations | endpoint_id | 내부 처리 |

| BE-API-005 | API 검색 | Method, Path 등을 기준으로 API 목록을 검색한다. | scan_id, q | 검색 결과 | GET /api/scans/{scan_id}/endpoints?q= |
| BE-API-006 | API 상세 조회 | 선택한 Endpoint의 Method, Path, 인증, 입력·출력 정보를 반환한다. | endpoint_id | Endpoint 상세 | GET /api/endpoints/{endpoint_id} |

| BE-REL-002 | 민감 Runtime 정보 제거 | 실제 Token과 Object ID가 LLM에 전달되지 않도록 검증한다. | LLM 입력 | 검증 결과 | 내부 처리 |

| BE-REL-004 | 관계 분석 저장 | API 관계, Module 후보, 선택 이유를 저장한다. | relationship_analysis.json | 저장 결과 | 내부 처리 |
| BE-PLAN-001 | 검사 계획 생성 | LLM Planner를 호출해 scan_plan.json을 생성한다. | relationship_analysis | scan_plan.json | 내부 처리 |
| BE-PLAN-002 | 검사 계획 검증 | Module, Operation, Runtime Binding을 검증한다. | scan_plan.json | 검증 결과 | 내부 처리 |
| BE-PLAN-003 | 검사 계획 저장 | 검사 계획 원본과 구조화 데이터를 저장한다. | scan_plan.json | plan_id | 내부 처리 |
| BE-PLAN-004 | 검사 계획 조회 | 저장된 검사 계획을 조회한다. | scan_id | scan_plan | GET /api/scans/{scan_id}/plan |
